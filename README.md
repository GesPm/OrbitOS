# OrbitOS> Demo:  https://gespm.github.io/OrbitOS/
OrbitOS is a personalized WebOS ( web based operating system), inspired by our Solar System ( or could be said inspired by space).
It's a personal project I made for the Stardance Challenge (mission: WebOS 1) and to learn HTML, CSS and JavaScript.

## OrbitOS Features:

- 🛰️ Solar System inspired desktop
- Draggable windows
- 🕐 Live clock
- 🧮 Calculator app
- 🚀 Random Solar System Fun Facts
- Welcome screen ( could be reopened by clicking OrbitOS in top left corner)
- Custom space-themed interface
- Interactive topbar

## Included Apps:
## Calculator (app)
A working calculator with:
- Numbers
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Result button

## Fun Facts (app)
A small app that randomly selects a fact about the Solar System whenever a new fact is requested ( limited facts sadly ).
The button is the middle text in the top bar ( yes I know very intuitive ).


## How it works:

OrbitOS is built using:
 HTML for the structure
 CSS for the design and layout
 JavaScript for interactions and functionality

## Why I made it:

I wanted to build something related to space while learning basic JS (coding).
Instead of making a normal website I decided to make a small WebOS where different features could exist as separate windows and apps so I could potentially learning more than making a basic website.
